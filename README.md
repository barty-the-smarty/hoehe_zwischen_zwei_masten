# Höhe zwischen zwei Masten

Interaktives Script, um die Höhe des Kreuzungspunktes von zwei Abspannseilen zu bestimmen. 
Die Höhe und der Abstand der zwei Masten kann mit der Maus in der Grafik eingegeben werden. 
Passend dazu werden zwei Abspannseile eingegefügt, die jeweils von einer Mastspitze zum 
gegenüberliegenden Mastfuß verlaufen. 
Die Position und Höhe des Kreuzungspunkte beider Seile wird ebenfalls angezeigt.

getestet mit Pyhton 3.11.9 benötigt MatPlotLib (pip install matplotlib)
